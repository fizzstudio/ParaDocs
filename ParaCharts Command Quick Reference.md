# ParaCharts Keyboard Commands: Quick Reference

For your convenience, here is a guide to the keyboard commands found throughout ParaCharts.

| Feature                             | Command             |
| ----------------------------------- | ------------------- |
| Add annotation                      | a                   |
| Toggle SparkBraille                 | b                   |
| Jump to cord landing                | c                   |
| Toggle data table                   | d                   |
| Toggle screen reader announcements  | e                   |
| Show the Help dialog                | h                   |
| Toggle Dark Mode                    | k                   |
| Toggle Low-Vision Mode              | l                   |
| Switch to other data set            | o                   |
| Query data                          | q                   |
| Repeat last message                 | r                   |
| Toggle Sonification mode            | s                   |
| Toggle Trend navigation mode        | t                   |
| Clear the data point selection      | u                   |
| Toggle Self-Voicing mode            | v                   |
| Open Chart Explainer                | x                   |
| Move the cursor                     | unspecified/unknown |
| Switch to adjacent navigation layer | unspecified/unknown |
| Play data points to the right       | Shift+End           |
| Play data points to the left        | Shift+Home          |
| Stop playing                        | Control             |
| Go to first point in series         | Home                |
| Go to last point in series          | End                 |
| Play or pause audio                 | Spacebar            |
| Reset the chart                     | +                   |
| Select a data point                 | Enter               |
| Extend the data point selection     | Shift+Enter         |
| Go to series minimum                | `[`                 |
| Go to series maximum                | `]`                 |
| Go to the chart minimum             | `{`                 |
| Go to the chart maximum             | `}`                 |
| Announce version info               | Control+Shift+V     |
| Stop speaking (Self-Voicing mode)   | Delete+Escape       |
|                                     |                     |
