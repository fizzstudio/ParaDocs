# ParaCharts Quick-reference Guide

For your convenience, here is a guide to the keyboard shortcuts found throughout the ParaCharts program. For more detailed best-use instructions, please see the directory titled "Manual Documentation."

Please Note: If you wish, you can change the input gesture for any command by visiting the "Controls" tab in the ParaCharts control panel by locating it in the table there, then pressing the "Edit" button. From there, you will be asked to enter the desired input gesture and save your changes.

| Feature | Keystroke |
| Add an Annotation | a |
| Toggle Screen Reader Announcements | b |
| Jump to Chord Landing | c |
| Toggle Data Table | d |
| Show the Help Dialog | h |
| Toggle Dark Mode | k |
| Toggle Low-Vision Mode | l |
| Toggle Tour Guide | n |
| Switch to Other Data Set | i |
| Query Data | q |
| Repeat Last Message | r |
| Toggle Sonification Mode | s |
| Clear the Data Point Selection | u |
| Toggle Self-Voicing Mode | v |
| Open Chart Explainer | x |
| Enter Trend Navigation Mode | Shift+Down Arrow |
| Exit Trend Navigation Mode | Shift+Up Arrow |
| Move the Cursor | [unspecified] |
| Move to Adjacent Navigation layer | [unspecified] |
| Play Data Points to the Right | Shift+End |
| Play Data Points to the Left | Shift+Home |
| Stop Playing | Control |
| Go to First Point in Series | Home |
| Go to Last Point in Series | End |
| Play or Pause Audio | Spacebar |
| Reset the Chart | + |
| Select a Data Point | Enter |
| Extend the Data Point Selection | Shift+Enter |
| Go to the Series Minimum | Left Bracket |
| Go to the Series Maximum | Right Bracket |
| Go to the Chart Minimum | Left Brace |
| Go to the Chart Maximum | Right Brace |
| Announce Version Info | Control+Shift+V |
| Stop Speaking (Self-Voicing Mode) | Delete+Escape |
